# AI3013 Telco Customer Churn Project - Member 4 KNN Package

This repository contains the current Member 4 KNN package for the AI3013 Machine Learning course project.

## Task

Binary classification on the Telco Customer Churn dataset.

- Positive class: `Churn = Yes` -> `1`
- Negative class: `Churn = No` -> `0`
- Main model in this package: K-Nearest Neighbors from scratch
- Evaluation: accuracy, precision, recall, F1-score, confusion matrix, and cross-validation

## Important implementation note

The KNN model is implemented from scratch with NumPy. It does not use scikit-learn, TensorFlow, Keras, or other machine learning model classes.

For KNN voting ties, this implementation predicts class `1`, which means `Churn = Yes`. This tie-breaking rule should be mentioned if discussing borderline KNN predictions in the report or presentation.

## Clean-clone run checklist

From a fresh clone of this repository:

1. Open a terminal in the repository root folder.
2. Create and activate a Python virtual environment if desired:

   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # macOS/Linux:
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the small KNN sanity check:

   ```bash
   python test_knn_small.py
   ```

5. Run the fast experiment:

   ```bash
   python run_fast_test.py
   ```

6. Run the full KNN experiment for report-ready outputs:

   ```bash
   python run_all.py
   ```

## How to run

Quick check:

```bash
python test_knn_small.py
```

Fast experiment:

```bash
python run_fast_test.py
```

Full experiment for the final report:

```bash
python run_all.py
```

Advanced users can also run the KNN experiment module directly from the repository root:

```bash
python -m src.run_knn_experiment --fast
python -m src.run_knn_experiment
```
