# Project Context for Codex

This repository is for our AI3013 Machine Learning course project.

## Current repo status

The current repository mainly contains Member 4's KNN part.

Main files:

- `src/preprocessing.py`: loads and preprocesses the Telco dataset
- `src/metrics.py`: from-scratch binary classification metrics
- `src/knn_scratch.py`: from-scratch KNN classifier
- `src/cross_validation.py`: from-scratch stratified 5-fold CV logic
- `src/run_knn_experiment.py`: runs the KNN experiment
- `run_all.py`: runs the current experiment entry point
- `README.md`: current instructions
- `data/WA_Fn-UseC_-Telco-Customer-Churn.csv`: dataset
